# Portfolio

Sitio personal de **Ramon** (software engineer), con React y Vite.

## Requisitos

- [Node.js LTS](https://nodejs.org/) (incluye `npm`)
- Git (opcional, para versionar)

## Arrancar

```bash
cd %USERPROFILE%\portfolio
npm install
npm run dev
```

Abre la URL que imprime Vite (normalmente `http://localhost:5173`).

## Personalizar

Edita `src/data.js`: nombre, textos, skills, proyectos, email y redes.

## Build

```bash
npm run build
npm run preview
```
